# Onboarding artwork

Original backgrounds generated with the built-in ImageGen tool on 4 November 2026. Optimized JPEGs are shared by native and web; public web copies live in `apps/web/public/onboarding`. Original generated PNGs remain in the local Codex generated-images library, outside the repository.

Prompt set: portrait, premium photographic background, no text, logos or interface elements, generous negative space, matching Circle.social black/orange palette.

- `ember.jpg`: flowing black satin folds with a luminous orange edge and dark upper negative space.
- `clouds.jpg`: peach cumulus clouds in a soft powder-blue sky.
- `botanical.jpg`: charcoal tropical leaves with subtle bronze light on their edges.
- `alpine.jpg`: serene gray alpine peaks beneath a pale cool sky.
- `city.jpg`: quiet modern city street in golden-hour amber haze.
- `midnight.jpg`: black satin and obsidian folds with restrained silver edges.

`fingerprint.svg` is a code-native decorative icon, rasterized to `fingerprint.png` for React Native. It is not a credential or biometric image. The onboarding feed preview is labeled sample content and does not represent implemented social posts.
